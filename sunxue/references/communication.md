# 传播方法

用于冷启动、项目发布、个人定位、公开回应和商业短文。需要文学叙事时转到 [写作方法](writing.md)；不要用文学的含混处理商业事实。

## 可观察的表达动作

以下是对不同材料的归纳，不是关于本人内心动机的结论。

| 动作 | 公开文本里的表现 | 转为工作方法时的限制 |
| --- | --- | --- |
| 把自己放进更大的变化 | 署名评论将技术趋势、地区条件和自身业务连接起来 | 说明你实际贡献哪一小步，不能只借时代名词抬高自己 |
| 用个人经历建立叙述位置 | 从升学、创业或技术使用经历进入公共议题 | 经历只证明经历，不能独自证明因果与普遍性 |
| 重写评价的问题 | 访谈中回应公众标签，并提出自己希望被评价的尺度 | 可以提出另一尺度，不能抹掉原问题或受损者 |
| 把熟悉的人物带进叙事 | 公开帖文以向知名创业者学习引出用户优先的立场 | 核实关系；“向某人学习”不等于“获得某人背书” |
| 让规模产生反差 | 商业表达使用规模与未来；小说让数字与人的缺席相撞 | 数字必须真实且有口径；反差不能靠编造损失或成功 |

出处包括 [2026 年署名评论](https://www.hkcd.com.hk/hkcdweb/content/2026/01/16/content_8735706.html)、[晚点节目](https://www.xiaoyuzhoufm.com/episode/68ad8fbc42cc2798e78224a6)、[用户优先帖文](https://www.linkedin.com/posts/justinsuntron_the-first-lesson-i-learned-from-jack-ma-and-activity-7199200020800184321-i2MB)。阅读方式及限制见 [来源说明](sources.md)。

## 冷启动或发布：先创造可以报道的事实

《Comedian》拍卖和慈善午餐公告提供了两个观察样本：人物通过一个明确的公开事件，进入已有受众的议题。把它理解为“构造一个可被报道的交点”是本包的分析，不是已证明的投资回报。普通用户可迁移的是事件与证据的组织，不能照抄当事人的支出规模；参加活动也不等于获得对方背书。[拍卖方记录](https://www.sothebys.com/en/articles/sothebys-fall-2024-auction-results)、[参与方公告](https://www.prnewswire.com/news-releases/tron-founder-justin-sun-wins-record-breaking-bid-for-warren-buffett-charity-lunch-300860485.html)

先确定一个受众，以及他现在遇到的一件事。把消息浓缩成一句：我们做成了什么，谁现在可以亲自检验。没有可检验的事实时，先提出小实验，不制造“重大官宣”。

可用结构是：变化正在发生 → 我们实际处在什么位置 → 这次做了什么 → 用户如何验证 → 下一次交付或更新时间。短帖可以只保留中间三项，不必每篇都从时代讲起。

### 发布前要知道

- 当前状态：原型、内测、公开可用，还是仅有计划。
- 证据：演示、可复查记录、真实案例或有口径的数据。
- 限制：支持范围、尚未解决的问题、付费或利益关系。
- 下一步：用户的一次具体行动，以及行动后会看到什么。

把实际成就写实，把志向写成志向。可以有雄心，但“我们希望”不能偷换成“我们已经”。不要把注册量写成活跃量，把测试用户写成付费客户，把意向写成合同，把一次会面写成合作。

### 分发与兑现一起设计

选能接触目标受众的渠道，不把“全网曝光”当默认目标。发布一份核心证据，再按平台改写开头与长度；不需要编造多个身份制造讨论。

在计划中区分两个阶段：

| 阶段 | 要回答的问题 | 可用指标 |
| --- | --- | --- |
| 看见与理解 | 谁看到了？是否明白是什么？ | 有来源的访问、有效询问、演示观看 |
| 使用与兑现 | 用户实际得到结果了吗？ | 激活、完成率、复用、退款、投诉 |

指标只选足够作决定的几个。实验阈值由资源和基线决定，没有历史数据时先测基线，不宣称某个转化率是行业标准。

## 争议回应：保留解释权，同时交代责任

用户可能想要强硬、有分寸的回应。先判断争议是事实错误、观点分歧，还是已经发生的损害。三者不能用同一套话术处理。

**事实错误。** 指出具体哪一项不成立，给可检查的证据，限定反驳范围。不能从“这一条不准确”跳到“所有批评都是恶意”。

**观点分歧。** 说明自己使用的评价尺度，以及为什么适用于当前问题；承认对方尺度仍能指出什么风险。

**实际损害或事故。** 顺序是：影响和受影响人 → 已确认事实 → 已做动作 → 未知事项 → 下一次更新时间与救济入口。只有动作确已执行才能使用完成时。

如果伤害属实，承认具体问题，比把它强行解释成“领先时代的代价”更可信。2019 年致歉材料仅用来提醒营销存在反作用，不把一封信扩展为全部事实结论。[公开转载](https://www.eeo.com.cn/2019/0725/362049.shtml)

### 有力度但不误导的回应结构

先准确复述别人质疑的核心，再区分可验证事实与价值判断。给出自己的立场，然后写明谁负责什么、如何验证、什么时候再更新。

不替用户承诺未知的赔付、修复进度或安全状态。缺少证据时直接说明未知，不用“绝对安全”“问题已经全部解决”“只是小概率”安抚。

## 三个常见误用

**借势变成虚构背书。** 可以借用公开议题，不能借用不存在的关系。需要赞助或合作时先取得对方授权，并如实披露。

**标签反转变成逃避回答。** 可以自嘲或换一个角度，但先答原问题。真实损失不因语言风趣而消失。

**热度变成唯一指标。** 只有触达没有兑现，就在消耗未来的信誉。先看承诺是否完成，再决定是否放大。
